What does this do?

Power BI Embedder allows embedding documents in Power Query M or DAX, bypassing size and file type limits.

You can use it to embed huge static mapping tables, or SVG images. The tool ensures the input is valid, escaped, and will be parsed correctly. It also provides various options to customise the generated code.
You can bring previously converted code to parse back into standard formats.
